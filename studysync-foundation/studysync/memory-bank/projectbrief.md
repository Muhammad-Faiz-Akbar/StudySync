# Project Brief

**StudySync** (Tim Ngawur, STACK 2026, Case 1: Smarter Campus and Learning): web app mobile-first yang mencocokkan mahasiswa sebagai teman belajar berdasarkan mata kuliah, jadwal kosong mingguan, dan tujuan belajar, lalu membantu menjadwalkan sesi.

- Alur inti: login kampus → isi mata kuliah dan jadwal → rekomendasi → koneksi / jadwalkan sesi.
- Tanpa AI. Data awal sintetis. Privasi jadwal granular. Target: onboarding < 2 menit, partner < 3 menit.
- Stack: Next.js + TypeScript + Tailwind + Supabase. Detail: `docs/09-DECISIONS.md`.

Dokumen acuan: `docs/01-PRD.md` (apa), `docs/03-MATCHING_ALGORITHM.md` (logika), `docs/04-DATA_MODEL.md` (data), `docs/02-PROJECT_PLAN.md` (urutan kerja), `.clinerules/` (aturan).
